# Galeria premium — domy i rezydencje

W tym folderze są przeznaczone do umieszczenia 4 zdjęcia z archiwum `cieploeko_premium_4_photos.zip`:

- `spa-dark-room.webp` — strefa SPA, zdjęcie główne
- `marble-bathroom.webp` — łazienka z marmurem
- `white-bathroom.webp` — jasna łazienka
- `radiator-detail.webp` — grzejnik w strefie SPA

Strona `domy-rezydencje-premium/index.html` ma już układ galerii i odwołania do tych plików. Tymczasowo podczas braku któregokolwiek z nich ładuje zdjęcie zastępcze z dotychczasowej galerii, by nie wyświetlać pustego kadru.

Publikacja do `main` dopiero po sprawdzeniu wszystkich 4 zdjęć.
