# Zdjęcia realizacji Ciepło Eko

Umieść tutaj zoptymalizowane pliki `.webp` z archiwum przygotowanego do galerii. W kodzie `index.html` znajduje się lista używanych nazw plików. Brakujące zdjęcia są automatycznie pomijane w galerii, a fotografia w sekcji „O nas” ma zastępczą wersję do momentu przesłania `automatyka-szafa-04.webp`.

Po przesłaniu plików sprawdź działanie galerii na telefonie i komputerze.
